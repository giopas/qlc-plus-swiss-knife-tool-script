# QLC+ Swiss Knife v3.8.0

## Stage layouts and per-song tempo

Two ideas from mjcmatrix (Matt C), [QLC+ wiki](https://github.com/mjcmatrix/qlcplus/wiki). The ideas are his, the code is not.

- **Per-song tempo.** Write `Song name | 128BPM` in the setlist, or fill the new BPM column. A badge tells you whether the matched chaser fits the tempo. *Apply to the show* times each step to the BPM and the beats per step, on a copy made for that song, so the original chaser and a chaser shared by two songs stay as they are. Claude's `setlist` tool reads and writes the tempo.
- **Stage layouts.** Save the stage and the band (riser, members, backline, wedges, backdrop, walkways) as a layout, share it through the Library, and start a show from it in Quick Start or in Stage & Meshes. Three layouts come built in: Full band, Acoustic and Festival. The Look Builder aims its places at the members, and Cabling takes its band floor from the meshes and can add the layout's walkways.

Full details: [CHANGELOG](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/blob/main/CHANGELOG.md).

# QLC+ Swiss Knife v3.4.1

## Seven languages, checked

The app was run in each of its languages (Italian, French, German, Spanish, Portuguese, Japanese, Chinese), screen by screen.

- About 120 strings per language that were still in English are translated: the Doctor's fixes and their options, what the Look Builder will add, the line after ✓ Apply, the History, the Stage & Meshes tips, the wizard roles and the places on the stage.
- Sentences are no longer half translated.
- Each language uses the same words everywhere: *lo show* in Italian, *el show* in Spanish, European Portuguese throughout, the same word for a route, a chaser or the console in German, Chinese and Japanese.
- Changing the language while the app is open now changes everything on screen.

## Also

- In a narrow window the route's steps stay on one line and slide to the current one.
- Tooltips with quotes in them are no longer cut short.
- New pictures in the README and the tutorial, and a new route GIF.

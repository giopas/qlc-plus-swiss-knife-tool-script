# QLC+ Swiss Knife v3.6.1

## Ready for the gig

No new screens. This release fixes what a real gig showed up, after the whole show path was checked on stage: the show opened, checked and played in QLC+, the Stage Monitor with the MIDI pedal and the tablet, a two-hour run, and a cabling plan used to pack.

- **Brightness** now finds fixture definitions in the macOS user folder (`~/Library/Application Support/QLC+/Fixtures`), where QLC+'s Fixture Editor saves them.
- **Show Paperwork** prints the cabling plan with the same fixture definitions as the Cabling screen, so a stock fixture's connector is known on paper too and the printed plan matches the screen.
- **Input profiles** for a MIDI pedal or controller are also found in the Windows user folder and in a QLC+ installed in `~/Applications` on the Mac.

Full details: [CHANGELOG](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/blob/main/CHANGELOG.md).

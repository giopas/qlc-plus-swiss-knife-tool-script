# QLC+ Swiss Knife v3.0.0

Version 3.0 is a milestone. The programme of work is complete: you can install Swiss Knife like an app, keep it up to date from inside, use it in English, Italian or French, and connect Claude to it. What changed is mostly the documentation, plus one fix.

## What 3.0 means

- **Install and update.** Download the package for macOS, Windows or Linux and double-click it. A badge tells you when a newer version is out, and *Update and restart* does the rest.
- **Three languages.** The interface speaks English, Italian and French.
- **Share what you build.** The Library moves VC templates, palettes, presets, naming profiles, VC styles and Show Profiles between people as one plain file.
- **Claude.** Connect Claude Desktop with one file, or Claude Code with one command. Claude gets only the folders you list and Swiss Knife itself, and it only writes new files. The menu says when the connection exists.
- **The same tools throughout.** Open a show once, change it with any tool, check it with the Doctor, save it as a new file with a report and a recipe, and do it again on another show with a profile.

## Changed in this release

- When a folder shared with Claude cannot be read (or does not exist), Claude is now told which one and why, and does not just report "no shows".
- The README, every wiki page and the work plan were rewritten in plain language and brought up to date. The wiki has a *Start here* section on its home page.
- The full working log moved to `docs/WORKPLAN_ARCHIVE.md`.

# QLC+ Swiss Knife v2.7.0 — Language and sharing

### Added
- **Interface in English, Italian and French** — pick the language at the bottom of the left menu. Text, tooltips and dialogs follow; your shows, reports, PDFs and the wiki stay as they are. Another language is one more JSON file in `static/i18n/`.
- **📚 Library** — share your VC templates, palettes, look presets, naming profiles, VC styles and Show Profiles as one plain file, and install what others shared. You see every item before anything is installed and choose skip / replace / keep both; the file is checked first. No server, no account, no network.
- Your own naming profiles and VC styles next to the built-in ones.

Your original files are never changed.

Full details: [CHANGELOG](../../CHANGELOG.md). Wiki: [Community Library](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/wiki/Community-Library), [Language](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/wiki/Language).

**Status:** the translations were written with an AI assistant and checked against the screens, not by a native reviewer — corrections are welcome (they are plain JSON files).

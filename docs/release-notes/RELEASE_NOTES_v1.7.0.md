# QLC+ Swiss Knife v1.7.0 — build the Virtual Console

### New
- **VC Builder** in the VC Visual Editor (right panel):
  - **Add** buttons, frames, solo frames, sliders, labels and CueLists — into the selected frame or the page, at the first free spot. **Delete** (Delete key) and **duplicate** (⌘D) the selection.
  - **Wire** widgets to functions: pick from a function list you can filter by type and by your naming profile's **group and effect letters**, or just **drag a function onto the canvas** — onto a button, CueList or slider to wire it, onto a frame or the page to add a new button there.
  - **Drag to move** selected widgets, snapped to the grid.
  - **Pages**: rename, reorder, make a page the first one (the one QLC+ opens on), delete.
  - **Label panel**: your naming legend (or any text) as a frame of labels in columns.
  - **Arrange by name group**: one row of buttons per naming group, in your profile's order.
  - **Screen profiles**: MacBook 1650 × 884, Full HD, tablet, iPad — resize a page or all pages, optionally scaling every widget.
  - **Page templates**: save a page and add it to another show; its buttons find their functions by name.
  - **Setlist CueList**: wire the setlist chaser to a CueList in one click.
  - Everything is undoable and saved as a new file with *Apply & Save QXW…*.

### Fixed
- The Workspace Doctor now sees the function of a slider in *playback* mode (no more false "not used" for it).

Your original files are never changed: every result is a new `.qxw`.

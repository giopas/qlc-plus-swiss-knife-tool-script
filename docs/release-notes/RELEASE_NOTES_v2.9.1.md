# QLC+ Swiss Knife v2.9.1: the card shows if Claude is connected

After you connect Claude Desktop, *🔌 Connect to Claude* used to look the same as before, with the same setup button. It now says where things stand.

## Changed

- A status line at the top of the card says whether Claude Desktop has Swiss Knife. When Claude has already used it, the line gives the date and time of the last start.
- A *Check again* button reads the status anew.
- Once you are connected, the setup button reads *Reinstall the connection*. To change the shared folders later, use *Settings › Extensions › QLC+ Swiss Knife* in Claude Desktop.
- Italian and French strings for the new lines.

Claude still gets only the folders you list and Swiss Knife's tools, and it only writes new files. The status check reads Claude Desktop's extension folder and settings file and Swiss Knife's own launcher log. It changes nothing.

Full details: [CHANGELOG](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/blob/main/CHANGELOG.md).

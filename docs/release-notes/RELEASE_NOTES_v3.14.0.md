### Changed — a clearer Song Builder (3.14.0)

- **Three blocks in order**: the song (name, tempo, time, how lengths are counted), the music, the parts. Opening a song built before is the first choice of the first block.
- **One choice for the music**: no music, a sound file (Browse…), a click track made for the song, or a sound already in the show. The length box only appears when the file's length can't be read.
- **A shorter parts table**: part, look, length, tempo and start. Repeat, fades, a tempo change and the chaser's steps are in a **⋯** panel on each row; a closed row shows what is set there as small tags.
- **Tempo on every row**, in colour where a part changes it and in grey where it carries on, so it is plain where a new tempo starts and stops.
- **Chaser steps only for a chaser**, as *its own timing / every beat / every 2 beats / every bar*. A scene is not offered steps, and steps are no longer sent for a scene.
- **To the end** is a button on the last row instead of typed text.
- **No Preview button**: the bar and the starts follow every key. The line beside *Build the Show* says what is left to do.
- **Start from a typical song** fills an empty table with Intro, Verse, Chorus, Verse, Chorus, Outro.
- The wiki *Song-Builder* page, its screenshot and all seven languages are updated.

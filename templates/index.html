Brightness

Scale the master dimmer of each fixture group across every scene. Colour ratios untouched.
—
How it works: Drag the sliders to scale the Master Dimmer channel of each fixture across every Scene in the loaded workspace. Colour ratios (R/G/B/W) are untouched. Use Link group to move all fixtures of the same model together. QXF definitions are auto-detected from your QLC+ installation (📁 Scan Local). If a fixture's QXF is still missing, 📂 Upload QXF it manually (multiple files supported) or use 🌐 Fetch from GitHub to download it from the official QLC+ repository (requires internet — you will be asked to confirm before any connection is made).

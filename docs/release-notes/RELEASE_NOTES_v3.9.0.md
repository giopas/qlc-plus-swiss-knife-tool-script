# QLC+ Swiss Knife v3.9.0

## Tablet on stage

What each player needs to know about the next song, on the stage tablet.

- **Song cards.** A card per song: tuning, tempo, who starts and how, a note, and a line per player for pedals and FX. Kept next to the show, so every version of it shares them. The Dictionary's text can be offered as a start.
- **Next song banner.** When the cue list reaches a new song, its card shows in large type for six seconds. A change of tuning from the song before is written in words and coloured.
- **A view for each player.** End the address with `?role=commander` (cues and the next card), `?role=band` (the card in full) or `?role=vocals` (names, tempo and note). Add `&who=Guitar` to show one player's line.
- **QR code.** The tablet opens the address, or a role view, by scanning. Made on the computer, with no network.
- **One entry.** The Stage Monitor and the Setlist's tablet page are now one screen, Tablet on stage, with two modes: Live monitor and Simple page.
- **Page kit.** A first set of shared parts (header, toolbar, sticky action bar that says what the main button does and why it is disabled). Only this screen uses it for now.

Not yet: cards in the Simple page, chosen VC buttons as tiles, the Setlist order on the live page.

# QLC+ Swiss Knife v2.5.0 — Looks and Stage

### Added
- **Look Builder**: chasers in QLC+ **beats** tempo; moving-head **positions** for looks and chasers; **your own palettes**; **RGB-matrix patterns for pixel bars** (with a dimmer-opening Collection when the bar has a master dimmer).
- **Stage & Meshes**: **aim fixtures** at a mesh or a point (tilt only); **hide / show** meshes; **thumbnails** in the mesh library.
- **Function Porter**: **copy meshes** between shows, keeping their place and height.

Your original files are never changed.

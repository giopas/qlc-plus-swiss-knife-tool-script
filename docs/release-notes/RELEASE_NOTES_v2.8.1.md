# QLC+ Swiss Knife v2.8.1 — a logo

QLC+ Swiss Knife has its own icon: a **Q whose tail is a folding knife**, with a red Swiss cross inside, on a dark tile.

### Added
- The icon on the app itself (macOS Dock and Finder, Windows taskbar), in the browser tab, in the header, and at the top of the README and the wiki.

### Nothing else changed
Same tools, same files, same shows. If you installed v2.8.0 from a package, this is the first release you can get with **Update and restart** (header badge → *Update and restart*).

*Status: the packages are built and smoke-tested by GitHub Actions; the macOS and Windows ones and the in-app update on those systems have not been tried live yet — please report anything odd.*

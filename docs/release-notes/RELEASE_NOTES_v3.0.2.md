# QLC+ Swiss Knife v3.0.2

The interface now speaks eight languages. German, Spanish, Portuguese, Japanese and Chinese join English, Italian and French.

## Language

- Pick the language at the bottom of the left menu, under *Files*, or press ⌘K / Ctrl+K and type *Language*. The browser remembers the choice.
- Menus, screens, tooltips and messages are translated, about 2,970 lines per language.
- Portuguese uses the European spelling (*ficheiro*, *ecrã*). Chinese is Simplified.
- Tool names and *Doctor* stay English everywhere. Your show's names, the reports, the PDFs and the wiki are not translated.
- A few strings that were English in every language now have a translation, among them the *🔌 Connect to Claude* menu item and *🔄 Auto-Map* in the Function Porter.

The new translations were written with an AI assistant and checked on the screens, not by native speakers. If a line reads badly, say so on the forum or open an issue with the corrected line. The [Language](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/wiki/Language) page explains where the words live.

Full details: [CHANGELOG](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/blob/main/CHANGELOG.md).

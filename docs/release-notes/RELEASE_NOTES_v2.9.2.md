# QLC+ Swiss Knife v2.9.2: the menu says when Claude is connected

The menu item *🔌 Connect to Claude* now reads *🔌 MCP connected to Claude*, in the accent colour, when Claude Desktop already has Swiss Knife. Without a connection it keeps its old label. Swiss Knife checks when it starts and again when you open the card. The check only reads Claude Desktop's extension folder and settings file and Swiss Knife's own launcher log, and it changes nothing.

Claude still gets only the folders you list and Swiss Knife's tools, and it only writes new files.

Full details: [CHANGELOG](https://github.com/giopas/qlc-plus-swiss-knife-tool-script/blob/main/CHANGELOG.md).
